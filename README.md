# Project pack: threat-modelling my three AI demos

A small set of project-management documents for a project I delivered in October 2026: threat-modelling three of my own public AI demos (a GDPR request classifier, a RAG chatbot and a radiology summariser), fixing what I could, and publishing the results.

**This is a retrospective pack.** I wrote it after delivery from my evidence log, report files and Git commit history. The dates are real. I did not set time estimates at the start, so there is no planned-versus-actual effort, and the review says so.

The project itself and its reports: https://github.com/ShivamKumar20-AI/ai-threat-model-reports

## What is in the pack

| # | Document | What it does |
|---|---|---|
| 1 | Project brief | Goal, what is in and out of scope, checkable success measures, stakeholders and constraints |
| 2 | Plan | Five milestones with deliverables, completion dates and dependencies, plus the critical path and one change made during delivery |
| 3 | RAID log | Risks, assumptions, issues and dependencies, including what really went wrong and what is still open |
| 4 | Progress updates | Three short stakeholder updates (done, next, blockers, status). The status colours are my own judgement, written afterwards |
| 5 | Review | Result against the brief, what went well, what did not, and what I would change next time |

Files: `Project-Pack-AI-Threat-Modelling.pdf` (the pack) and the `.html` source.

## Limits
